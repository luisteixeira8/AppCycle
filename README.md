> **AppCycle** is a cross-platform mobile application developed as the final project for the Bachelor's degree in Software Engineering. Built using **Flutter** and **FlutterFlow**, it leverages **Firebase** for backend services.

---

## 📱 Project Overview

**AppCycle** aims to help the enviroment by reducing textile and eletronic waste by helping people to recycle this types of waste. This project demonstrates the integration of modern mobile development tools to create a seamless user experience on both Android and iOS.

### ✨ Key Features
* **User Authentication:** Secure login and registration using Firebase Auth.
* **Cross-Platform:** Runs smoothly on both Android and iOS.
* **Real-time Database:** Utilizes Cloud Firestore for instant data updates.

---

## 🛠️ Tech Stack

* **Framework:** [Flutter](https://flutter.dev/) (Stable Channel)
* **Language:** [Dart](https://dart.dev/)
* **Development Tool:** [FlutterFlow](https://flutterflow.io/)
* **Backend:** [Firebase](https://firebase.google.com/) (Auth, Firestore, Storage)
* **State Management:** FlutterFlow default / Provider
